1. Open Transport / Configuration / Routes and create a route with an
   origin and a destination. Both locations need a latitude and a
   longitude, unless the provider can geocode the address.
2. Add intermediate stops on the **Ordered stops** page. Drag them into
   the driving order. A stop can override the location coordinates.
3. Choose the routing provider and press **Compute route**.
4. The job writes the distance and the estimated time on the route, in
   the route units. A provider error is stored on the route.
