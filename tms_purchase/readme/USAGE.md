## Purchase vehicles
1. Go to Purchase module.
2. Create a new purchase quotation for the **Demo Cargo Truck** product (demo data).
3. Add the vehicle product and confirm the order.
4. Click **Receive Products** or use the smart button to validate the receipt.
5. The fleet vehicle is created with the purchase order date, receiving location, and line amount.

## Purchase from trips
1. Go to Transport module.
2. Create or select a trip.
3. Click the **Purchases** smart button to view linked purchase orders or create a new one.
4. The purchase will be linked to the trip automatically.
