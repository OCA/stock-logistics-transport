Import live positions, odometer readings, and fuel fills from a
telematics provider. Provider modules only log in and translate their
payload. This module stores the reading once, links the device to a
Fleet vehicle, writes the Fleet odometer when the value changes or the
ignition turns off, and copies departure and arrival readings onto the
open trip.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Configuration
=============

Install a provider module, such as Geotab, and the OCA ``queue_job``
module. Load ``queue_job`` in the server-wide modules and run Odoo with
workers. The pull cron queues one job per active account on the channel
``root.telematics``.

Create an account under Transport / Configuration / Telematics Accounts.
Set the provider, server, database, login, and password. The webhook
address is ``/tms/telematics/hook/<account id>`` and it expects the
header ``X-Telematics-Token``.

Usage
=====

Open the telematics account and press Pull. The job imports new events.
A position updates the device coordinates. A trip start or trip end
writes the departure or arrival odometer on the open trip for that
vehicle, in the vehicle odometer unit. A fuel fill is stored on the
reading. A later module can turn that fill into an expense.

The same external id is imported once. Posting it again does not create
a second reading.
