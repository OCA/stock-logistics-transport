## Demo database

To try the integration, register and create a trial database. A Geotab
demo database is a temporary environment (at most 60 days) with sample
data you can use to explore the features.

1. Open the MyGeotab registration page.
2. Click Continue on **Create a demo database**.
3. Fill in your contact information. Use your existing MyGeotab
   credentials if you already have them, or reset your password through
   MyAdmin if you need to.
4. Set the demo options:
   - Expiry: choose when the database expires (up to 60 days).
   - Profession, vehicle type, and location: select the vocation, the
     vehicle type, and the place used for the simulation.
   - Fleet size: choose how many simulated vehicles to include (10 to 50).
5. Enter a unique database name. That name is used in the database URL.
6. Click Submit, then choose **Log in to my database** on the
   confirmation screen.

Demo databases are deleted automatically after 60 days at most. They
hold simulated data for testing. To try the integration against newer
Geotab features, use `preview.geotab.com`.
