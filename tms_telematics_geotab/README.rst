Pull a Geotab database, including an AT&T Fleet Management federation
host, into TMS telematics. The module logs in with JSON-RPC, follows the
server returned by Authenticate, and maps LogRecord, Trip, and FillUp
feeds. Odometer values arrive in meters and are stored in kilometers.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

On the telematics account, choose the provider Geotab. The server
defaults to ``https://my.geotab.com/apiv1``. For AT&T Fleet Management,
set the server to the AT&T host. Fill in the Geotab database, the
service user, and the password.

Usage
=====

Press Pull on the account. The job keeps a feed cursor per Geotab object
and continues from that cursor on the next run. A Trip becomes a trip
start and a trip end. The end odometer is the Geotab value converted
from meters to kilometers, and the start odometer is that value minus
the trip distance.
