Turn a telematics fuel fill into a fuel expense on the vehicle. The
expense uses the receipt amount sent by the provider, or the fuel
product cost when the provider sends liters only. Distance allocation
then splits that amount across the trips that ran between this fill and
the previous one.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

Install this module from Transport settings, under Connect telematics.
The Fuel product must be allowed on expenses. Set its cost to the price
per liter when the telematics provider does not send the receipt amount.

Usage
=====

1. Match the telematics device to a vehicle, and set that vehicle's
   driver.
2. Import a fuel fill. Odoo creates a fuel expense for the driver, at
   the odometer reading of the fill.
3. The amount is the receipt sent with the fill. When the provider sends
   liters only, the amount is the liters times the fuel product cost.
4. The existing fuel allocation splits that amount across the trips
   whose odometer readings fall between this fill and the previous fill
   of the same vehicle.
5. Open the fill reading to see the expense.
