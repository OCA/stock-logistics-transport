Compute a predefined route with OpenRouteService. A location without
coordinates is geocoded from its address. When the route avoids tolls,
the request asks for a path without tollways.

Configuration
=============

The company OpenRouteService API key is set in Transport settings. The
key is sent as the Authorization header. The driving profile is
``driving-car``.

Usage
=====

1. In Transport settings, paste the OpenRouteService API key.
2. Open a route, set the provider to OpenRouteService, and press Compute
   route.
3. The distance and estimated time come from the returned path. Enable
   Avoid tolls to keep the path off toll roads.
