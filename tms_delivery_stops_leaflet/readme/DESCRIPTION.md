This module extends the TMS Delivery Stops module with Leaflet map visualization
and stop selection capabilities.

**Features:**

* Map view for delivery stops using Leaflet
* Group stops by TMS order (trips)
* Drag-and-drop resequencing of stops within and between orders
* Checkbox selection for unallocated stops (group "Sem Viagem")
* Create delivery orders directly from selected stops on the map
* Numbered markers with route polylines
* Google Maps navigation integration
