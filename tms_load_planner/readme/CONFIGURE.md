## Layout

1. Go to Transportation > Configuration > Fleet Models > Models.
2. Open a vehicle model.
3. On the Layout page, set the loading length and the door width and height
   on the model. Those dimensions are the box drawn in the planner.
4. Add one row per slot. The code is the name shown in the planner, for
   example ROW-03-LEFT.
5. X is meters from the front of the box, Y is meters from the left side,
   and Z is meters up from the floor.
6. Upload a top view when you have one. The left edge of the picture is the
   front, and the top edge is the left side.

Vehicles of that model receive one space for each slot. Open a vehicle and
use the Spaces list to block a space that must stay empty.
