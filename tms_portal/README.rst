opens the assigned trips and records pickup lines for the cargo that was
sold.

Configuration
=============

In Transport settings, enable External drivers. That installs this
module.

Create a portal user whose contact is the driver contact. The driver
then sees only trips where they are the assigned driver.

Usage
=====

The portal home shows Pickups. Open a trip and add a pickup line under
the sold cargo with the description, pieces, weight, and volume that
were loaded.
