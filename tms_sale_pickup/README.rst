Record what was picked up against the cargo sold on a trip, and invoice
the difference when the trip is completed.

A sold cargo line stays as quoted. The driver adds one or more pickup
lines on that same trip. Weight and volume services can be priced from
those quantities. A distance service is priced from the difference
between the two odometer readings. When the trip is completed, a draft
invoice or credit note covers the gap with any amount already billed.

Configuration
=============

On the trip service, set the factor to Distance, Weight, or Volume and
choose the unit.

An internal driver uses a normal user in the Driver group, linked
through the driver contact. That user sees only the trips assigned to
them.

External drivers use a portal user on the same contact. Enable them from
Transport settings with External drivers, which installs the portal
module.

Usage
=====

Add the cargo on the sale order line before confirmation. Confirming the
sale freezes those quantities.

On the trip, add a pickup line under the sold cargo with the pieces,
weight, and volume that were loaded. An internal driver does this on My
pickups. A portal driver does this from the portal once External drivers
is enabled.

For a distance service, record the departure and arrival odometer on the
trip. Completing the trip sets the billed factor from the odometer
difference, or from the sum of the pickup lines for weight and volume.

If nothing has been invoiced and the trip is set to create the invoice
on completion, that invoice uses the billed factor. If an invoice
already exists, completing the trip adds a draft invoice or a draft
credit note for the difference. The posted invoice is left as it is.
