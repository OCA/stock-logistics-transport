Add the cargo on the sale order line before confirmation. Confirming the sale freezes those quantities.

On the trip, add a pickup line under the sold cargo with the pieces, weight, and volume that were loaded. An internal driver does this on My pickups. A portal driver does this from the portal once External drivers is enabled.

For a distance service, record the departure and arrival odometer on the trip. Completing the trip sets the billed factor from the odometer difference, or from the sum of the pickup lines for weight and volume.

If nothing has been invoiced and the trip is set to create the invoice on completion, that invoice uses the billed factor. If an invoice already exists, completing the trip adds a draft invoice or a draft credit note for the difference. The posted invoice is left as it is.
