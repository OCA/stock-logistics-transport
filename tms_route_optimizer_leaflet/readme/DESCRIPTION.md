This module provides Leaflet map visualization for TMS orders with
optimized routes.

Features:

- Leaflet map view for TMS orders
- Polylines showing optimized route geometry
- Numbered markers for delivery stops in sequence order
- Sidebar with route metrics (distance, duration)
- Click to center on stop location
- Google Maps navigation links

Integrates tms_route_optimizer with web_view_leaflet_map to provide
rich visual representation of delivery routes.
