This module provides Leaflet map visualization for TMS orders with
optimized routes.

Features:

- Leaflet map view for TMS orders
- Polylines showing optimized route geometry
- Numbered markers for delivery stops in sequence order
- Sidebar with route metrics (distance, duration)
- Click to center on stop location
- Google Maps navigation links

Integrates tms_route_optimizer with web_view_leaflet_map to provide rich
visual representation of delivery routes.

Usage
=====

Viewing Routes

::


   1. Navigate to TMS > Orders
   2. Select an order with delivery stops
   3. Click on the "Map" button or use the map view

   The map displays:

   - Numbered markers for each delivery stop
   - Blue polyline showing the optimized route
   - Sidebar with total distance and estimated time
   - Click on a stop to center the map

   Navigation
   ~~~~~~~~~~

   Click on any stop marker to open the popup with:

   - Stop address and details
   - "Navigate" button to open Google Maps directions
